# PLOS-AI 学习操作系统 14 模块扩展 - 产品需求文档

## Overview
- **Summary**: 在现有 PLOS-AI（Python + PyQt6 + SQLite + Ollama + RAG）基础上，新增 14 个功能模块，覆盖数据备份、知识图谱、艾宾浩斯复习、仪表盘、多账号、新手向导、日志面板、富文本笔记、教材缓存、模型管理、批量导入、试卷模板、语音、专注模式、插件接口。
- **Purpose**: 构建完整的个人学习闭环，提升易用性与答辩亮点，同时保证硬件降级、数据安全、主题适配。
- **Target Users**: 个人学习者（本地离线使用为主）。

## Goals
- 补全学习闭环：复习调度 → 知识图谱 → 仪表盘统计 → 数据备份。
- 强化数据安全与多账号隔离。
- 所有新增功能严格按硬件内存分级降级。
- 不破坏现有 10 项已有功能。

## Non-Goals
- 不改动现有 Ollama 硬件调度、RAG、OCR、启发式教学、自适应出题、主观题批改、试卷导出、主题切换、侧边导航、并发限制的业务逻辑。
- 不实现云端同步（仅本地数据）。
- 不实现完整插件生态，仅预留接口与 UI 框架。

## Background & Context
- 现有硬件分级仅两档（`is_high_spec` / `is_low_spec`），阈值 RAM≥16G 或 VRAM≥8G。需扩展为三档。
- 现有 `users` 表无密码字段；`conversations`/`messages`/`documents`/`chunks`/`error_book`/`flashcards`/`study_logs` 七张表无 `user_id` 字段，数据隔离不完整。
- 已有 `knowledge_graph_panel`、`dashboard_panel`、`settings_panel`、`user_panel`、`backup_service` 等骨架，需增强。
- 日志模块已用 `RotatingFileHandler`，需扩展清理旧日志与日志面板。

## Functional Requirements

### 基础设施
- **FR-INFRA-1**: 硬件分级从两档改为三档：≤7GB 低配、8~12GB 中配、>12GB 高配；设置页保留"强制低配模式"开关。
- **FR-INFRA-2**: 为 `conversations`/`messages`/`documents`/`chunks`/`error_book`/`flashcards`/`study_logs` 补 `user_id` 字段并建立索引，所有读写按当前用户隔离。
- **FR-INFRA-3**: 用户表增加密码哈希字段（PBKDF2/SHA256），不存明文。

### 模块1：数据备份与导入导出
- **FR-1.1**: 设置页增加"数据备份管理"子页面。
- **FR-1.2**: 一键导出当前账号全部数据（错题、笔记、RAG向量、学习计划、答题记录、配置）为 `.plosbackup` 归档。
- **FR-1.3**: 导出前校验数据库完整性，损坏则警告。
- **FR-1.4**: 支持定时自动备份（每天/每周退出时），可设最大保留份数，默认 5 份。
- **FR-1.5**: 导入 `.plosbackup` 前二次确认"将覆盖当前账号所有数据"；失败不破坏现有库。
- **FR-1.6**: 分项导出：错题本、笔记文档，格式 JSON。
- **FR-1.7**: 仅导出当前登录账号数据，不导出其他账号。

### 模块2：知识图谱
- **FR-2.1**: 主界面"知识图谱"页按学科→章节→知识点构建树状脑图。
- **FR-2.2**: 节点掌握率 = 答对/总作答；≥80% 绿、40~79% 黄、<40% 红。
- **FR-2.3**: 节点可点击弹窗：查看习题、关联教材片段、相关笔记。
- **FR-2.4**: 支持缩放、拖拽画布、搜索定位。
- **FR-2.5**: 内存 ≤12GB 时入口自动隐藏。
- **FR-2.6**: 配色随主题切换。

### 模块3：艾宾浩斯复习 + 仪表盘
- **FR-3.1**: 记录每题作答时间、对错、AI 评估的记忆难度，按 1/3/7/15/30 天节点计算复习时间。
- **FR-3.2**: 首页"待复习"卡片显示今日复习数，点击进入复习。
- **FR-3.3**: 后台运行时到点弹出非阻塞提醒，可推迟 1/3 天。
- **FR-3.4**: 完成复习后更新记忆周期。
- **FR-3.5**: 仪表盘卡片：今日时长/答题数/正确率、知识点掌握率柱状图、错题分类统计、周趋势折线图。
- **FR-3.6**: 生成周/月报告并导出 PDF。
- **FR-3.7**: 内存 ≤7GB 时仪表盘隐藏图表，仅纯文本数字。

### 模块4：多用户账号
- **FR-4.1**: 启动先弹账号选择窗（首次除外）。
- **FR-4.2**: 新建账号（用户名+密码，密码加密存储）、删除（二次确认+清数据）、切换。
- **FR-4.3**: 账号间错题/笔记/计划/RAG/记录/配置完全隔离。

### 模块5：新手向导
- **FR-5.1**: 首次启动自动弹出 5 步向导；设置页可重跑。
- **FR-5.2**: 步骤：欢迎 → 硬件检测展示内存与推荐模型 → 选择本地/云端模式 → 模型配置 → 完成。
- **FR-5.3**: 向导支持深浅色主题。

### 模块6：运行日志面板
- **FR-6.1**: 设置页→系统日志，实时滚动查看。
- **FR-6.2**: 搜索关键词。
- **FR-6.3**: 一键打包日志为 zip。
- **FR-6.4**: 单日志 5MB 轮转，自动删除 30 天前旧日志。

### 模块7：富文本笔记 + 截图批注
- **FR-7.1**: "笔记"导航页，支持笔记本文件夹分类。
- **FR-7.2**: 富文本编辑：加粗/斜体/标题/列表/插图/粘贴图片/OCR文本。
- **FR-7.3**: 截图批注：截图→画笔标注→文字批注→插入笔记。
- **FR-7.4**: 选中内容可 AI 提炼考点/生成自测题/总结摘要。
- **FR-7.5**: 笔记可绑定知识点/习题双向跳转。

### 模块8：教材缓存管理
- **FR-8.1**: 教材页"缓存管理"按钮，展示每本教材名称/大小/下载时间。
- **FR-8.2**: 删除单本 / 一键清空。
- **FR-8.3**: 磁盘上限设置，到顶提示不再下载。
- **FR-8.4**: 内存 ≤7GB 关闭离线缓存，仅在线预览。

### 模块9：Ollama 模型管理面板
- **FR-9.1**: 设置页→本地模型管理，展示已下载模型列表、大小、显存预估。
- **FR-9.2**: 一键启动/停止模型（调 ollama stop）。
- **FR-9.3**: 实时刷新 Ollama 服务与模型加载状态。

### 模块10：批量题库导入
- **FR-10.1**: 题库页"批量导入"，支持 .xlsx/.docx。
- **FR-10.2**: 自动解析题干/选项/答案/得分点/知识点/难度。
- **FR-10.3**: 导入前预览并可手动修改。
- **FR-10.4**: 格式错误提示，不污染现有库。

### 模块11：试卷导出模板
- **FR-11.1**: 模板配置：字体/字号/行距/页边距。
- **FR-11.2**: 答案选项：文末 / 独立参考答案文件。
- **FR-11.3**: 可选是否标注知识点。

### 模块12：语音朗读与输入
- **FR-12.1**: TTS 朗读题目/解析；语音输入提问。
- **FR-12.2**: 降级：<8G 隐藏入口；8~12G 默认关闭手动开；>12G 默认开。
- **FR-12.3**: 设置音色/语速。

### 模块13：专注学习模式
- **FR-13.1**: 首页"专注模式"按钮，隐藏侧边栏只留题目与答题区。
- **FR-13.2**: 内置计时器（开始/暂停/结束），时长计入仪表盘。

### 模块14：插件扩展接口
- **FR-14.1**: 架构预留插件加载入口、规范接口、目录结构。
- **FR-14.2**: 插件管理页面（UI + 接口框架）。

## Non-Functional Requirements
- **NFR-1**: 所有 IO/模型调用/硬件读取/DB 读写包 try-except，失败弹中文提示并回退低配。
- **NFR-2**: 数据绝不上传互联网，仅用户手动开启云端 API 或主动下载教材时联网。
- **NFR-3**: 新增窗口/面板/控件同时适配深浅色主题，风格统一。
- **NFR-4**: 侧边栏保留滚动布局，不破坏页面跳转。
- **NFR-5**: 全局单 AI 请求并发限制，后台推理不阻塞 UI。
- **NFR-6**: 日志 5MB 轮转，30 天清理。

## Constraints
- **Technical**: Python 3.10+, PyQt6, SQLite, Ollama, 现有项目结构。
- **Business**: 最小差异补丁，不改已有功能业务逻辑。
- **Dependencies**: 现有 `hardware.py`、`user_service.py`、`backup_service.py`、`main_window.py`、`schema.sql`。

## Assumptions
- 用户本机已安装 Ollama 或可使用云端 API。
- 向量库（Chroma）按账号独立目录存储。
- 现有仪表盘/知识图谱面板可增强而非重写。

## Acceptance Criteria

### AC-1: 硬件三档分级
- **Type**: `rule`
- **Given**: 硬件检测模块
- **When**: 模拟 RAM=6/10/16 GB
- **Then**: 分别判定为 low/mid/high
- **Pass Condition**: `get_hardware_tier()` 返回对应档位
- **Evidence**: 单元测试输出

### AC-2: 强制低配开关
- **Type**: `rule`
- **Given**: 设置中 `force_low_spec=true`
- **When**: 任意硬件
- **Then**: 所有功能按低配运行
- **Pass Condition**: `is_low_spec_forced()` 返回 True
- **Evidence**: 配置读取测试

### AC-3: 数据隔离完整性
- **Type**: `rule`
- **Given**: 两个账号 A/B 各录入错题
- **When**: 切换账号
- **Then**: A 看不到 B 的数据，反之亦然
- **Pass Condition**: 查询结果按 user_id 过滤
- **Evidence**: 双账号冒烟测试

### AC-4: 备份导出/导入往返
- **Type**: `rule`
- **Given**: 账号有错题和笔记
- **When**: 导出 .plosbackup 后清空再导入
- **Then**: 数据完整恢复
- **Pass Condition**: 记录数一致
- **Evidence**: 备份往返测试

### AC-5: 自动备份轮转
- **Type**: `rule`
- **Given**: 设保留 3 份
- **When**: 连续备份 5 次
- **Then**: 仅保留最新 3 份
- **Pass Condition**: 目录文件数 ≤3
- **Evidence**: 文件计数

### AC-6: 知识图谱降级
- **Type**: `rule`
- **Given**: RAM≤12GB
- **When**: 加载侧边栏
- **Then**: 知识图谱入口隐藏
- **Pass Condition**: 导航项不可见
- **Evidence**: 模拟低配启动

### AC-7: 艾宾浩斯调度
- **Type**: `rule`
- **Given**: 一道昨天答对的题
- **When**: 计算复习时间
- **Then**: 下一次复习日符合 1/3/7/15/30 节点
- **Pass Condition**: 日期差正确
- **Evidence**: 调度算法测试

### AC-8: 仪表盘低配降级
- **Type**: `rule`
- **Given**: RAM≤7GB
- **When**: 打开仪表盘
- **Then**: 不渲染图表，仅数字
- **Pass Condition**: 无 QChart/matplotlib 组件
- **Evidence**: 组件检查

### AC-9: 多账号启动选择
- **Type**: `rule`
- **Given**: 存在多个账号
- **When**: 程序启动
- **Then**: 弹出账号选择窗
- **Pass Condition**: 选择窗可见
- **Evidence**: 启动流程测试

### AC-10: 新手向导首次触发
- **Type**: `rule`
- **Given**: settings 无向导标记
- **When**: 首次启动
- **Then**: 弹出 5 步向导
- **Pass Condition**: 向导窗口显示
- **Evidence**: 首次启动测试

### AC-11: 日志轮转与清理
- **Type**: `rule`
- **Given**: 日志文件 >5MB
- **When**: 写入新日志
- **Then**: 自动新建文件；30 天前文件删除
- **Pass Condition**: 单文件 ≤5MB，旧文件清理
- **Evidence**: 日志目录检查

### AC-12: 富文本笔记保存
- **Type**: `rule`
- **Given**: 新建笔记含加粗/图片
- **When**: 保存后重开
- **Then**: 格式与图片保留
- **Pass Condition**: HTML 内容一致
- **Evidence**: 保存读取测试

### AC-13: 模型管理启停
- **Type**: `rule`
- **Given**: Ollama 服务在线
- **When**: 点击停止模型
- **Then**: 模型从内存卸载
- **Pass Condition**: ollama list 不再显示该模型
- **Evidence**: 命令输出

### AC-14: 批量导入预览
- **Type**: `rule`
- **Given**: 合法 xlsx
- **When**: 导入
- **Then**: 显示预览表格，确认后入库
- **Pass Condition**: 记录数与预览一致
- **Evidence**: 导入测试

### AC-15: 试卷模板导出
- **Type**: `rule`
- **Given**: 配置字体/答案分离
- **When**: 导出
- **Then**: Word 文件按模板生成，答案单独文件
- **Pass Condition**: 两个文件生成且内容正确
- **Evidence**: 文件检查

### AC-16: 语音降级
- **Type**: `rule`
- **Given**: RAM<8GB
- **When**: 加载界面
- **Then**: 语音入口隐藏
- **Pass Condition**: 无语音按钮
- **Evidence**: 组件检查

### AC-17: 专注模式
- **Type**: `rule`
- **Given**: 首页
- **When**: 点击专注模式
- **Then**: 侧边栏隐藏，计时器显示
- **Pass Condition**: 侧边栏不可见，计时器运行
- **Evidence**: UI 状态检查

### AC-18: 插件接口框架
- **Type**: `rule`
- **Given**: 插件目录
- **When**: 放置符合接口的插件
- **Then**: 可被加载器发现
- **Pass Condition**: 插件出现在列表
- **Evidence**: 加载测试

### AC-19: 异常不崩溃
- **Type**: `rule`
- **Given**: Ollama 断开 / DB 损坏 / 坏备份包
- **When**: 触发对应操作
- **Then**: 弹中文提示，程序不退出
- **Pass Condition**: 进程存活
- **Evidence**: 异常注入测试

### AC-20: 主题适配
- **Type**: `rubric`
- **Dimension**: 新增页面深浅色主题一致性
- **Scale**: 1-5
- **Anchors**: 1 = 文字反转/控件错乱; 3 = 基本可读但配色不统一; 5 = 完全匹配现有主题
- **Pass Threshold**: >= 4
- **Evidence**: 深浅色截图比对
