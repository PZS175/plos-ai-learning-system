# PLOS AI · 一页版作品简介

> 用途：申报书"作品简介"栏、展板、初评速览页。全文约 600 字，可直接粘贴或按栏目字数删减。

**作品名称：** PLOS AI——基于本地大模型的离线个人学习操作系统

**一句话介绍：** 一套能在普通家用电脑上完全离线运行、数据不出本机的 AI 学习系统，把"讲义问答—拍照识题—错题管理—间隔复习—自适应练习—组卷导出—学习计划"串成一条闭环。

**为什么做：** 现有的学习工具存在四个问题——学习机价格高（3000 元以上且部分功能按年付费）；拍照搜题类应用要把题目照片上传云端，而学生的错题集合正是他知识薄弱点的完整画像；通用 AI 能答疑但不理解学习管理，聊完即忘；搜题应用直接给答案，缺少教学法约束。

**做了什么：** 作品在本地部署轻量化大模型（文本、视觉、向量三类全部本机推理），实现了 19 项主功能、24 个界面模块、41 个业务服务模块。学生导入讲义后可"结合自己的资料"提问；拍下的错题照片先经纯 CPU 图片增强（去手写笔迹、背景净化、几何校正，0.1 秒级），再由本地视觉模型识别并自动排版成数学公式，一键进入错题本并自动标注知识点、题型与难度；错题会驱动闪卡复习（间隔重复）、自适应练习与学习计划——新增一道错题，系统会自动向当前计划插入针对性复习任务并留下可查的调整记录。

**技术特点与创新点：**

1. **零依赖的公式混排渲染引擎**：不使用任何第三方数学排版库，自行实现 LaTeX 到富文本的转换，并贯通到表格、列表与文档导出（Word 原生公式、PDF 上下结构分式）；
2. **错题驱动的闭环编排**：以错题作为驱动信号，让学习计划随学习状态动态变化，而不是静态表格；
3. **不依赖模型的图片增强**：区分手写笔迹与印刷内容，避免误删表格框线，显著提升识别前质量；
4. **带教学法约束的对话**：可切换讲解式/追问式，支持"不直接给答案"，并可配置讲解深度与教学风格；
5. **以架构保证数据主权**：本地推理 + 强制离线锁 + 多用户隔离 + 带回滚的备份还原；
6. **硬件自适应**：按内存显存推荐 7B/3B 模型套装，低配自动降级并如实提示。

**验证与结果：** 通过 304 项自动化测试、41 项模拟真实使用（数据目录置于空白沙箱、真实调用本地模型）的端到端检查，以及打包产物自检。在纯 CPU 推理的普通电脑上，语义检索约 0.1 秒、结合知识库的问答 7～14 秒、练习卷导出 0.9 秒；断网状态下全部核心功能可用。测试过程中发现并修复了四个"不报错但真实存在"的缺陷（导出 PDF 因字体未子集化达 18.68 MB、知识库相关度显示为负数、硬件推荐 7B 实际运行 3B、离线计划模板七天任务重复），每个缺陷均补充了回归测试。

**交付形态：** Windows 安装包（405 MB），无需管理员权限，不需要独立显卡；模型下载完成后可完全断网使用。
