# PLOS AI · 安装与运行说明

> 给评委老师或第一次接触本作品的人：照着这份说明，10 分钟内可跑起来。全程不需要管理员权限，也不需要付费账号。

---

## 一、运行环境要求

| 项目 | 最低 | 推荐 |
|---|---|---|
| 系统 | Windows 10 / 11（64 位） | Windows 11 |
| 内存 | 8 GB（自动降级为 3B 模型） | 16 GB 以上（7B 模型） |
| 磁盘 | 约 8 GB（程序 + 模型） | 12 GB |
| 显卡 | 不需要，纯 CPU 可运行 | 有独立显卡更快 |
| 网络 | **不是必需**（仅首次下载模型时需要） | — |

## 二、安装步骤

1. 双击安装包 `PLOS_AI_Setup_2.3.1.exe`；
2. 安装程序**不需要管理员权限**，默认装到当前用户目录：`%LOCALAPPDATA%\Programs\PLOS AI`；
3. 安装向导中可勾选"创建桌面快捷方式"（默认勾选）；
4. 安装完成后可直接从安装向导启动，或双击桌面图标启动。

> 卸载：使用开始菜单中的"卸载 PLOS AI"。**卸载会保留你的学习数据**（数据在同一安装目录下的 `data` 文件夹），如需彻底清理请手动删除该目录。

### 关于安装位置（如果报 Error 5 拒绝访问）

程序默认把 `data / config / logs` 放在**安装目录下**（便携设计：整个文件夹拷走就带走全部数据），因此安装目录必须是当前用户可写的位置。默认路径（C 盘用户目录）一定可写，直接用即可。

如果想装到 D 盘等其他位置，而你的目标目录（或它的上级目录，例如 `D:\APP`、`D:\Program Files`）**当前用户没有写权限**，安装程序会报：

```
Setup was unable to create the directory "D:\APP\PLOS AI".
Error 5: 拒绝访问。
```

这时有三种做法（任选其一）：

1. **换一个自己有权限的目录**，例如 `D:\PLOS AI`、`D:\我的软件\PLOS AI`（先在资源管理器里试着手动新建文件夹，能建就说明有权限）；
2. **改用管理员身份安装**：在安装向导的**第一页把安装模式改为「为所有用户安装（需要管理员权限）」**，通过 UAC 确认后再把目录改成 D 盘目标位置；也可以直接右键安装包 →「以管理员身份运行」，然后在向导第一页选择"为所有用户安装"；
3. **使用默认目录**（C 盘用户目录），最简单，也不用管理员权限。

> 新版安装包已做两处改进：①安装向导在"选择目标位置"一页会**先做一次写入测试**，不能写会当场提示原因和处理办法，不会再出现装到一半报错；②即使安装目录不可写，程序运行时也会自动把数据改存到 `%LOCALAPPDATA%\PLOS AI`，不会出现"装上了却打不开"。

## 三、首次启动：准备本地模型

程序启动时会自动探测本机的模型服务：

**情况 A：本机已安装 Ollama 并有模型**
启动引导会显示"检测到文本模型 / 视觉模型"，并告知使用了哪一套（7B 或 3B）。直接点"进入主程序"即可。

**情况 B：本机没有 Ollama**
按下面两步装好即可（命令在 Windows 终端中执行）：

```
# 1) 安装 Ollama（官网下载 Windows 版并安装）
#    https://ollama.com/download

# 2) 拉取模型（按机器配置二选一）
#    高配（内存 16G 以上）
ollama pull qwen2.5:7b-instruct-q4_k_m
ollama pull qwen2.5-vl:7b-q4_K_M

#    低配（内存 8G 左右）
ollama pull qwen2.5:3b-instruct-q4_K_M
ollama pull qwen2.5-vl:3b-q4_K_M

#    向量模型（知识库检索用，很小）
ollama pull nomic-embed-text
```

装好模型后重启程序，启动引导即可正常进入。程序内也提供了"一键下载缺失模型"的入口。

**情况 C：完全不想装模型**
程序仍可使用除 AI 之外的全部功能（错题本、闪卡、练习、学习计划、统计、备份、插件），并在界面上如实提示"AI 功能不可用"；也可以在设置中改接云端 API（需要自备 Key，默认关闭）。

## 四、第一次使用建议（3 分钟走一遍）

1. 打开左侧「仪表盘」→ 点快捷入口里的「加载演示数据」；
2. 依次点开「错题本」「闪卡」「练习」「学习计划」「学习诊断」，这些不需要模型就能看；
3. 到「AI 对话」问一句和学习相关的问题，第一次回答会慢一些（模型要加载进内存），之后会明显变快；
4. 到「知识库」拖一份讲义（Word / PDF / Markdown / TXT 都行）进去，再提问，可以看到它"结合我的讲义"回答；
5. 到「OCR」导入一张题目照片，先看图片增强的效果，再看识别与公式排版结果。

> 演示前建议：把模型**预热**一次（随便问一句、随便识别一张图），这样正式演示时不会有首次加载的等待。

## 五、离线使用说明

- 模型的下载完成之后，程序可以在**完全断网**的状态下使用：对话、识别、出题、复习、导出、备份全部可用；
- 设置页有「强制纯离线锁」：打开后会隐藏云端配置与教材导入入口，从结构上关闭所有联网路径；
- 程序中**不包含任何数据上传或遥测逻辑**，学习数据只保存在本机 `data` 目录。

## 六、数据与备份

| 内容 | 位置 |
|---|---|
| 数据库 | 安装目录 `data\plos.db` |
| 向量库 | 安装目录 `data\chroma\` |
| 题目图片与附件 | 安装目录 `data\images\`、`data\attachments\` |
| 自动备份 | 安装目录 `data\backups\auto\` |
| 设置文件 | 安装目录 `config\config.toml` |
| 运行日志 | 安装目录 `logs\plos.log` |

> 如果安装目录不可写，程序会自动把以上 `data / config / logs` 改放到 `%LOCALAPPDATA%\PLOS AI\` 下（运行时日志里会有一条提示），功能不受影响。

- 支持**自动滚动备份**（按天/按周，保留份数可配置）与**手动完整备份**（含图片附件，导出为单个备份文件）；
- 还原时带失败回滚保护，中途出错会恢复到还原前的状态；
- 换电脑迁移：把备份文件拷过去，在新机器上还原即可。

## 七、常见问题

**Q：提示"未检测到视觉模型 / 图片功能不可用"？**
A：说明缺少视觉（VL）模型。按第三节的命令拉取对应模型即可；在此之前，错题本、闪卡、练习等功能不受影响。

**Q：识别一张图要 20 秒左右，是不是卡住了？**
A：不是。视觉模型完全在本机 CPU 上运行，首次调用包含模型加载，约 20 秒属正常；之后会快一些。界面上有进度提示。

**Q：导出的 PDF 里中文变成方块？**
A：本程序导出时已嵌入并**子集化**中文字体，通常不会出现。若第三方阅读器显示异常，请用 Edge、Chrome 或 Adobe Reader 打开。

**Q：安装时被杀毒软件拦截？**
A：这是未签名的个人作品程序，部分杀毒软件会提示"未知发布者"。可加入信任后继续；本程序不联网自动更新。

**Q：能装在没有独立显卡的旧笔记本上吗？**
A：可以。程序会自动识别内存与显存并选择 3B 档位模型，同时关闭视觉识别与图表组件，只保留文字能力，界面上会明确提示已降级。

**Q：换台电脑要重新配置吗？**
A：程序会重新探测硬件并推荐模型套装；学习数据通过备份文件迁移。

## 八、卸载与清理

1. 开始菜单 →「卸载 PLOS AI」；
2. 卸载不会删除学习数据（位于 `%LOCALAPPDATA%\Programs\PLOS AI\data`），需要在卸载前先导出备份；
3. 如需彻底清理，卸载后手动删除整个 `%LOCALAPPDATA%\Programs\PLOS AI` 目录。
