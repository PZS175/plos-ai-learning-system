## 1. 项目概述

PLOS AI 是一个**完全离线运行**的个人学习桌面应用，面向中小学生与自学者，将 AI 辅导、错题管理、间隔记忆、自适应练习、试卷测评、学习计划与学习诊断整合为一套"个人学习操作系统"。

- **技术形态**：PyQt6 桌面应用 + 本地 Ollama 大模型推理 + SQLite 本地存储
- **交付形态**：PyInstaller 安装目录（`dist/PLOS AI/`），解压双击即用
- **规模**：19 个功能面板、30 个业务服务、27 张数据表、101 项自动化测试

### 1.1 项目背景

市面学习产品分四类，各有结构性缺陷：

| 阵营 | 代表 | 缺陷 |
|------|------|------|
| 硬件学习机 | 讯飞/步步高 | 售价 3000-6000 元，功能按年付费，系统封闭 |
| 搜题 App | 作业帮/小猿/夸克 | 强制上传题目照片（隐私），答案导向不教学，广告与订阅 |
| 通用 AI | ChatGPT/豆包 | 不做学习管理：无错题本、无遗忘曲线、对话结束即遗忘 |
| 记忆工具 | Anki/Quizlet | 制卡成本极高，无 AI 辅助，界面陈旧 |

PLOS AI 以"**本地离线 × 全闭环 × 教学法约束 × 习惯激励**"四要素组合，规避上述全部缺陷。

### 1.2 目标用户

| 用户 | 核心诉求 | 对应能力 |
|------|---------|---------|
| 学生（初/高中） | 拍题解答、错题不丢、考前复习有章法 | OCR 搜题、错题本、闪卡、试卷、智能队列 |
| 家长 | 了解学习情况但不想装监控 | 每日学习记录、家长 PDF 报告（本地生成） |
| 教师 | 给学生出变式题、组卷 | 变式题生成、试卷导出 Word/PDF |
| 自学者 | 知识管理与记忆 | 知识库 RAG、术语词典、听写跟读 |

## 2. 产品定位

**"数据永不离开这台电脑的 AI 学习机。"**

三条产品铁律：

1. **拼场景闭环，不拼模型智力**——竞品需要 3 个 App + 手动搬运的流程，PLOS 一键完成
2. **数据燃料飞轮**——自适应难度、遗忘曲线、错因画像、薄弱图谱以用户私人数据为燃料，越用越准
3. **零门槛到第一次"哇"**——安装包双击启动，10 分钟内完成"拍照→解答→入库→变式"全流程

## 3. 硬性技术栈（交付态）

| 层 | 技术 |
|----|------|
| UI | PyQt6（+QtWebEngine 教材导入） |
| 推理 | Ollama（本地） / OpenAI 兼容云端 API（可选），模型套装 7B/3B 按硬件自适应 |
| 检索 | ChromaDB + nomic-embed-text 本地嵌入 |
| 语音 | faster-whisper（ASR）+ 内置 TTS |
| 存储 | SQLite（WAL + 外键 + 版本化迁移 v3） |
| 打包 | PyInstaller（`tools/build_installer.py`，含冒烟自检） |

## 4. 整体架构

```
UI 层（19 面板 + 组件）
  ↓ 调用
服务层（30 个服务，AppContext 容器统一装配）
  ↓ 依赖
AI 层（ModelManager 多后端） / 数据层（SQLite + 迁移） / 工具层
```

关键设计（详见 [ARCHITECTURE.md](ARCHITECTURE.md)）：

- **AppContext 服务容器**：25+ 服务依赖装配集中于 `core/context.py`
- **版本化迁移**：`PRAGMA user_version` + 只增不改的幂等迁移链（当前 v3）
- **主题令牌系统**：深浅双主题 40+ 令牌单一权威源，全应用零硬编码色值
- **线程安全**：Database 进程内 RLock + `transaction()` 原子上下文
- **离屏 UI 回归**：19 面板 × 双主题 28 张截图自动渲染走查

## 5. 功能需求详述（按面板）

### 5.1 总览仪表盘

| 功能块 | 需求描述 | 数据来源 |
|--------|---------|---------|
| 四大统计卡 | 总题数/已掌握/待复习/今日专注时长，实时刷新 | 错题本 + 闪卡 + 统计表 |
| **专注模式** | 番茄钟（25 分钟专注 + 5 分钟休息），可选科目；自然完成自动记录时长，手动结束按实际分钟记录（不足 1 分钟提示不记录）；暂停/继续/跳过休息 | 写入 statistics_records |
| **今天学什么（智能队列）** | 三源聚合排序：SM-2 到期闪卡(P95) + 薄弱知识点重练(P85) + 本周计划任务(P75)；每项含推荐理由，点击直达对应面板 | 三表聚合 |
| **学习热力图** | 近半年（26 周）GitHub 风格网格，色阶 = 当日专注分钟；悬停显示明细；今日格描边 | statistics_records |
| **每日目标** | 目标分钟数可在设置页配置（默认 30），卡片显示"今日 X/Y 分钟" + 进度条 | 统计表 + 配置 |
| **本周学习速览** | 本周 vs 上周：专注时长/新增错题/复习量/复习正确率，带 ↑↓ 趋势箭头 | 多表聚合 |
| **错因画像** | 四象限（概念不清/计算失误/审题偏差/知识空白）+ 每象限训练处方；归类规则：AI 批改错因关键词优先，无记录按掌握度降级推断 | 错题本 + 批改表 |
| **今日复习提醒** | 有到期闪卡时显示横幅，一键开始复习 | 闪卡表 |
| **AI 学习计划** | 展示本周计划与任务进度，空状态引导创建 | 计划表 |
| **演示数据** | 一键加载/重置演示数据（重置需二次确认——会清空当前用户全部学习数据） | 演示服务 |

**验收要点**：闪卡评分、番茄钟结束等行为发生后，热力图/队列/周报在下一次刷新中可见变化。

### 5.2 AI 对话

- **多轮对话**：本地 Ollama 或云端 API，流式打字机输出（首字 <2s），显示推理耗时
- **教学风格**：苏格拉底追问模式；"禁止直接给出答案"硬约束（提示词层强制）；讲解深度分级（基础版避免抽象术语）
- **知识增强**：可勾选引用知识库（RAG）与错题上下文
- **渲染**：Markdown + LaTeX 数学公式（matplotlib 渲染为图，三级回退保证不裸露源码）
- **辅助**：回答可语音朗读（TTS）；会话多管理、清空、删除
- **交互**：Ctrl+F 全局搜索、Ctrl+1~9 面板切换

**异常处理**：模型未启动 → 明确报错并指引"模型管理"面板；返回为空/解析失败 → 显示失败原因与原始输出片段（进日志）。

### 5.3 OCR / 搜题

- **单张识别**：选择图片/截图/剪贴板粘贴（Ctrl+V），VL 视觉模型提取文字或直接解题
- **批量识别**：多张试卷图片逐张识别并切分题目，进度条实时反馈，单张失败不断批
- **全流程一键入库**：识别 → AI 解答 → 批量入库 → 学习计划联动 → 前 3 题生成变式
- **自动打标**：录入错题时 AI 自动补全知识点标签（独立限流线程池，并发 ≤2）
- **全局热键**：任意界面截图/剪贴板直达 OCR
- **大图优化**：超过 2048px 自动等比缩放副本识别（原图不受影响）

### 5.4 知识库（RAG）

- PDF/文本文档导入，分块嵌入 ChromaDB
- 语义检索：输入问题返回相关文档片段
- 教材导入：内置浏览器接入国家中小学智慧教育平台，教材详情页一键导入（需登录时可用"外部浏览器打开"兜底 + 知识库手动上传）
- 附属：网页剪藏、思维导图生成、Mermaid 图表渲染与编辑、文档批注

### 5.5 错题本

- 录入：手动 / OCR / 批量导入；字段含科目、章节、知识点、难度、掌握度（0-2）
- AI 能力：自动打知识点标签、主观题结构化批改（得分点/失分点/错因/改进建议）、**变式题生成**
- 管理：筛选（科目/标签/难度/掌握度）、收藏、右键菜单、Ctrl+S 保存
- 导出：JSON / CSV / Markdown
- **联动**：错题掌握度变化自动触发学习计划动态调优（调整留审计记录）

### 5.6 闪卡复习

- SM-2 间隔重复算法（ease/interval/repetitions/next_review）
- 到期队列自动生成；键盘流：空格翻卡、1(忘记)/2(困难)/3(良好)/4(简单) 评分
- 复习行为自动写入统计（供正确率与队列使用）
- 制卡：手动、错题一键转卡、批量导入

### 5.7 自适应练习

- 按知识点出题，题型五种（选择/填空/判断/简答/开放）
- 难度自适应：正确率 100% 升星、0% 降星、中等维持（1-5 星）
- 判分：客观题本地归一化比对（秒出），主观题 AI 批改
- JSON 容错：围栏剥离/尾逗号/全角标点/**非法反斜杠转义修复**/截断数组恢复 + 自动重试一次，失败附原始输出片段

### 5.8 试卷生成

- 按知识点集合 + 题型数量 + 难度区间组卷
- 长题型分批生成（每批 2 题）避免输出截断
- 导出 Word（python-docx）与 PDF（PyMuPDF）
- 试卷删除保留题库

### 5.9 学习计划

- AI 生成周计划（每日任务含科目/时长/描述）
- 科目边界约束：从真实错题/闪卡收集科目分布注入提示词，防止"英语计划混入数学"
- **动态调优**：错题新增/掌握度变化自动调整，触发与调整内容留痕可查
- 任务完成度跟踪

### 5.10 学习诊断

- 一键生成复盘报告：学习习惯、薄弱点、改进建议

### 5.11 家长/教师报告

- 本地生成 A4 PDF：本周概览/错因画像与处方/薄弱点 TOP5/给家长的话
- 文件名自动带日期，保存路径自选，数据不出门

### 5.12 语音

- **语音转文字**：本地 Whisper（面板一键安装引擎），录音波形可视化
- **听写跟读**：TTS 播报原文 → 学生作答（键盘/ASR）→ 评分（中英归一、漏词/多词明细、分档反馈）

### 5.13 知识图谱

- 节点 = 知识点（错题数/练习正确率/平均掌握度），分类着色（薄弱红/待巩固黄/较扎实绿）
- 边 = 知识点共现（粗细 = 次数），双薄弱关联用警示色，悬停显示关系说明
- **补课路径**：关联薄弱点成组连排、组内错题多者先补，理由可解释，图上直接展示顺序
- 力导向布局固定种子（同图刷新布局一致）

### 5.14 术语词典

- 从 OCR 结果与文档阅读提取术语，记录来源与上下文
- 支持手动维护

### 5.15 学习包

- 导出：错题/闪卡/计划/任务/批注/术语/文档 任选组合，zip 格式带校验
- 导入：分享码或文件，数据校验后合入
- **AI 智能组包**：描述需求（"期末复习，函数与导数"），AI 读取资源分布自动勾选并填标题描述
- **WebDAV 同步**：挂用户自有网盘（坚果云/OneDrive/自建 NAS），上传/下载/列表/删除

### 5.16 教材导入

- 内置浏览器（QtWebEngine）接入国家中小学智慧教育平台
- 教材详情页启用导入，下载 PDF 自动入知识库
- 兜底："外部浏览器打开"按钮 + 知识库手动上传
- 版权提示内置

### 5.17 用户管理

- 多账户创建/重命名/切换/删除（当前用户删除保护）
- 每用户数据物理隔离（所有业务表按 user_id 隔离）
- 概览：错题/闪卡/文档数、累计专注分钟、最近学习日期

### 5.18 模型管理

- 本地 Ollama / 云端 API 双后端切换
- 模型套装 7B/3B 按硬件自动推荐，可手动指定
- 健康检测 + 运行日志面板
- 温度/最大 Token/上下文长度参数可调

### 5.19 偏好设置

- 深浅双主题实时切换（全应用令牌级跟随）
- 演示模式（UI ×1.25 投屏）
- 每日学习目标分钟数
- 日志级别
- 最小化到托盘

## 7. 功能创新点

### 7.1 产品层

1. **全离线学习操作系统闭环**（★★★）：搜题→错题→记忆→练习→测评→计划→复盘全链路单机完成；SaaS 竞品因商业模式无法复制
2. **本地学习分析**（★★★）：热力图/连续天数/周报/错因画像全本地计算，零遥测
3. **单机多用户隔离**（★★）：一台电脑多学生各用各的
4. **学习 + 投屏双形态**（★★）：演示模式一键放大 1.25×

### 7.2 AI 编排层

5. **硬件自适应模型套装**（★★★）：按内存/显卡自动匹配 7B/3B 成对套装
6. **视觉大模型直接识题**（★★★）：手写体与数学公式友好，置信度门控降级
7. **主观题结构化批改**（★★★）：得分点/失分点/错因/建议四段分色渲染
8. **教学法约束内置**（★★★）：苏格拉底模式 + 禁止直接给答案 + 讲解分级
9. **可解释计划调优**（★★★）：错题变化自动调计划，调整留痕
10. **全链路优雅降级**（★★）：任一模型缺失只禁对应功能

### 7.3 数据层

11. **行为→统计→激励管线**（★★★）：真实学习行为自动点亮全部可视化
12. **数据零锁定**（★★）：全量导出 + 学习包分享 + 每日自动滚动备份
13. **隐私默认**（★★★）：数据不出本机；家长报告本地生成

### 7.4 工程层

14. **双主题令牌系统**（★★）：单一权威源 + 运行时切换
15. **版本化迁移**（★★）：幂等迁移链 + 热点索引
16. **自检 CLI**（★★）：doctor 一键体检五类健康项
17. **离屏 UI 回归门禁**（★★★）：28 张双主题截图自动走查
18. **平台级 bug 根治**（★★）：PyQt6 崩溃规避 / zh_HK 数字乱码 / WebEngine 初始化顺序，均入文档防复发

## 9. 约束与已知边界

1. 本地 7B/3B 模型通用智力弱于云端旗舰——产品设计以结构化工作流弥补，不打通用问答
2. 桌面端专属（Windows），暂无移动端
3. 教材导入需联网且建议登录智慧教育平台；教材版权归出版社，仅限个人学习
4. 语音转写首次使用需下载 Whisper 模型
5. 未代码签名：首次运行需通过 SmartScreen 确认
6. 进程退出偶见无害的日志 Handler 打印（已知噪音，不影响功能）
