# PLOS AI 个人学习操作系统 - 产品需求文档

## 1. 项目概述

**PLOS AI**（Personal Learning Operating System AI）是一款面向个人用户的本地离线 AI 学习桌面应用。它致力于将多模态学习资料（截图、文档、网页、手写笔记等）统一采集、理解、存储与复习，构建属于用户个人的“第二大脑”。所有数据默认保存在本地，模型可调用本地 Ollama / llama.cpp 或兼容 OpenAI 的 API，兼顾隐私性与灵活性。

## 2. 产品定位

- **目标用户**：大学生、考研/考证人群、终身学习者、需要管理大量错题与知识卡片的自学者。
- **核心场景**：
  1. 截取屏幕题目或错题，自动 OCR 识别并解析知识点。
  2. 导入 PDF、Word、图片等资料，建立可检索的个人知识库。
  3. 与本地大模型对话，基于 RAG 获取答案并自动关联原文出处。
  4. 通过闪卡与错题本进行间隔重复复习。
- **价值主张**：在完全离线环境下，也能获得接近在线 AI 助手的学习辅助体验，同时保证数据主权与隐私安全。

## 3. 硬性技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 语言 | Python >= 3.11 | 类型提示、异步、现代标准库 |
| UI 框架 | PyQt6 >= 6.6 | 跨平台桌面 GUI |
| 本地模型 | Ollama / llama.cpp | 默认本地推理，无需联网 |
| 在线兼容 | OpenAI 兼容 API | 可选云端模型 |
| OCR | PaddleOCR + 视觉语言模型双流水线 | 印刷体与复杂排版兼顾 |
| 向量库 | ChromaDB | 本地向量检索 |
| 嵌入模型 | sentence-transformers | 文本与多模态嵌入 |
| 文档解析 | PyMuPDF、python-docx、Pillow | PDF/Word/图片处理 |
| 配置管理 | TOML + Pydantic v2 | 强类型配置校验 |
| 日志与异常 | 结构化日志 + 全局异常捕获 | 便于问题定位 |

## 5. P0 核心功能

### 5.1 多模态输入
- 支持快捷键全局截图、区域截图、剪贴板图片。
- 支持导入 PDF、DOCX、PNG/JPG、纯文本文件。
- 自动提取文件元数据（文件名、页码、创建时间、来源类型）。

### 5.2 双 OCR 流水线
- **印刷体流水线**：PaddleOCR 快速提取文字，适合清晰的电子资料与截图。
- **视觉语言模型流水线**：本地 VLM（如 MiniCPM-V、Qwen-VL）理解复杂排版、公式、手写体与图文混排。
- 流水线可配置优先级、兜底策略与并行执行。

### 5.3 图像内容识别
- 识别题目类型（选择、填空、解答、证明）。
- 提取题干、选项、答案、解析区域。
- 对公式区域进行 Latex/MathML 化（优先通过 VLM）。

### 5.4 AI 对话
- 多轮对话，支持系统提示词模板。
- 可切换本地模型与在线模型。
- 对话历史持久化到 SQLite。

### 5.5 RAG（检索增强生成）
- 对导入资料分块、嵌入并写入 ChromaDB。
- 对话时自动检索相关知识块作为上下文。
- 答案附带引用来源（文档名 + 页码/段落）。

### 5.6 错题本
- 截图识别后一键加入错题本。
- 字段：科目、标签、错误原因、掌握程度、下次复习时间。
- 支持按科目、标签、时间筛选与导出。

### 5.7 闪卡
- 自动生成正面/背面闪卡。
- 基于 SM-2 间隔重复算法调度复习。
- 复习结果反馈更新记忆参数。

### 5.8 模型管理
- 列出已安装/可用模型。
- 切换默认对话模型、Embedding 模型、OCR/VLM 模型。
- 检测本地 Ollama 服务状态与硬件信息。

### 5.9 配置系统
- 全局配置 + 用户本地配置覆盖。
- 热重载部分配置项。
- 配置项包含：模型端点、快捷键、OCR 策略、UI 主题、数据路径等。

### 5.10 异常捕获
- 全局未处理异常捕获与弹窗提示。
- 关键操作异常自动记录到 logs/。
- 崩溃时生成 traceback 快照，便于用户反馈。

## 6. P1 后续功能

- 语音输入与 TTS 朗读。
- 学习时长统计与专注模式。

- 多语言界面与多用户配置隔离。

## 7. 创新点与约束

### 创新点
- **本地优先**：核心功能无需联网，避免学习资料上传云端。
- **双 OCR 流水线**：兼顾速度与复杂场景理解。
- **学习闭环**：采集 → 理解 → 存储 → 复习 → 反馈，全部在一个应用内完成。
- **模型无关**：底层抽象 `AIClient`，可接入 Ollama、llama.cpp、OpenAI 等。

### 约束
- 默认必须支持离线运行；联网功能只能作为可选增强。
- 依赖体积与显存要求需在文档中明确说明。
- 禁止上传用户学习资料到任何第三方服务，除非用户明确授权。
- 所有持久化数据路径由配置系统统一管理，避免硬编码。

## 8. 非功能要求

- **性能**：截图到 OCR 结果返回 < 3s（本地 GPU 加速），对话首 token < 5s。
- **可维护性**：模块职责清晰，核心接口通过抽象基类定义。
- **可测试性**：Services 层与 AI 层单元测试覆盖率 > 60%。
- **可移植性**：支持 Windows / macOS / Linux，优先保证 Windows 体验。
- **稳定性**：崩溃率 < 1%，关键 IO 操作加 tenacity 重试。
- **隐私**：本地向量库、本地数据库、本地日志，默认不上传。

## 10. MVP 验收标准

1. 应用能正常启动并展示主窗口。
2. 可配置本地 Ollama 模型并验证连通性。
3. 支持截图或导入图片，通过 PaddleOCR 提取文本并展示。
4. 支持导入 PDF/DOCX，建立 ChromaDB 向量索引。
5. 基于资料内容进行问答，答案能引用来源。
6. 截图识别后可将题目加入错题本，并设置标签与复习时间。
7. 闪卡按 SM-2 算法推送复习，用户可评分并更新下次复习时间。
8. 全局异常能被捕获并写入 logs/，应用不因非致命异常崩溃。
9. 配置修改后可保存并在重启后生效。
10. 所有 P0 功能在离线环境下可独立运行。
