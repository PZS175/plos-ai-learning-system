# PLOS AI 路线图

> 原则：本地优先、隐私默认、离线可用。每一阶段都保持
> 「pytest 全绿 + ruff 干净 + 双主题截图走查」的发布门槛。

## P1 企业级底座（已完成，v0.2.0）+ 学习闭环（v0.3.0：番茄钟/每日目标/周报速览/复习统计接线）

- [x] 版本化数据库迁移 + 热点索引
- [x] AppContext 服务容器
- [x] 每日自动滚动备份
- [x] CLI 运维工具（doctor/backup/migrate/version）
- [x] CI + pre-commit + 架构/开发文档
- [x] 学习热力图 + 连续天数

## P2 数据与洞察（下一站，实用向）

- [x] 学习周报（仪表盘速览版）：本周 vs 上周时长/错题/复习/正确率；诊断报告深度复盘仍在计划中
- [ ] 记忆保持率曲线：基于 SM-2 的历史复习数据估算每个知识点的记忆衰减，可视化「遗忘悬崖」
- [ ] 练习错因标签体系：判分时让模型输出结构化错因（概念不清/计算失误/审题偏差），错题本按错因聚合
- [ ] 数据导出开放格式：一键导出全部学习数据为 JSON + Markdown（无锁定，可迁移）

## P3 平台化（前瞻向）

- [ ] 插件系统：定义面板/服务注册协议（manifest + 入口点），第三方可以扩展新面板而不改核心代码
- [ ] 事件总线：跨面板解耦（错题新增/复习完成/用户切换改为发布-订阅，替代现有点对点刷新）
- [ ] i18n 框架：文案收敛为资源表，为多语言做准备（zh-CN 为默认语言）
- [ ] 模型抽象层升级：统一本地/云端能力探测与降级策略，支持自定义 OpenAI 兼容端点

## P4 分发与运维

- [ ] PyInstaller 打包规范（含 Paddle 模型、ChromaDB 的 hook）+ 安装包
- [ ] 增量更新通道：检查更新只下载差异（可选，尊重离线环境）
- [ ] 崩溃报告本地化：崩溃时在本地生成脱敏报告文件，由用户自行决定是否提交
- [ ] Windows 代码签名（消除 SmartScreen 警告）

## P5 体验深化（创新向）

- [ ] 无障碍：键盘全导航、高对比度主题变体、系统缩放联动
- [ ] 学习意图识别：根据最近行为（连续错某知识点/多日未复习）主动建议下一步动作
- [ ] 多设备同步（可选功能）：以学习包为载体的端到端加密同步，不经服务器明文
- [ ] 知识图谱驱动出题：从图谱薄弱节点自动规划练习路径，替代单纯按知识点出题

## 技术债看板

- [ ] `ruff` 规则从 `F,E9` 扩展到全量 lint（需一次性清理历史）
- [ ] UI 层类型标注覆盖（mypy 从 `warn_unused_configs` 起步）
- [ ] 面板构造函数参数瘦身：统一改为接收 `AppContext` 子集
